# Bank Management System (C)

A console application for managing bank accounts, written in C as a first-year project at EMSI Morocco.

## Features

- Add multiple accounts with unique account numbers
- Three account types: Savings (3%), Checking (1%), Youth (5%)
- General statement sorted by balance, with interest calculation
- List of accounts sorted by name
- Search an account by name
- Deposits and withdrawals with balance checks

## Technologies

- C (standard library: `stdio.h`, `stdlib.h`, `string.h`)
- Structs, arrays, pointers, sorting algorithms

## How to run

```bash
gcc main.c -o bank
./bank
```
